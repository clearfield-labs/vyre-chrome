Or do it by hand
  1. Press the download button above and unzip the file into your home folder (the one with your name). You get a folder called Vyre for Chrome.
  2. In Chrome, open a new tab and go to chrome://extensions . Turn on Developer mode (top right). Press Load unpacked and choose the extension folder inside Vyre for Chrome.
  3. Ask Claude Code or Codex: "Run the setup in my Vyre for Chrome folder." Then quit and reopen the app, and ask it to run chrome_status. It says connected.

Set it up for your firm

Your firm decides which websites it may use. Just ask, in plain words:

Set up Vyre for Chrome for our firm. It may only use our GoHighLevel and our website.
Show me which websites Vyre for Chrome may use.
Always ask me before you press Disable, Revoke, Transfer or Make admin.

Safe by design

  • Sends, posts, payments and deletes wait for your yes.
  • Passwords, cookies and tokens are hidden from the AI.
  • Banks, password managers and sign-in pages are never touched.
  • Only the websites your firm allows. Everything else is refused.
  • Press Esc in the page, or Cmd+Shift+E (Ctrl+Shift+E on Windows), to stop it at once.

Tip: use a separate Chrome profile, signed in only to the sites it should use.

If something is off

It says "not connected"
Make sure Chrome is open and the extension is loaded in chrome://extensions. Quit and reopen Claude Code or Codex after the setup. Only one Claude Code or Codex window can drive the browser at a time, so close the others.
Chrome warns about developer mode extensions
That is normal. It appears because you loaded the extension yourself instead of from the Chrome Web Store.
Chrome says it "started debugging this browser"
That is normal while Vyre for Chrome works in a tab. It goes away when it stops.
Chrome says "Manifest file is missing"
You picked the wrong folder. Choose the extension folder inside Vyre for Chrome, not Vyre for Chrome itself.
A Mac says "node" cannot be opened
Ask Claude Code or Codex to run the setup in your Vyre for Chrome folder. It clears the download mark macOS puts on new files, then it opens normally.
